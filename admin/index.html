¿No tienes un token todavía?
  1. Entra a github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens
  2. "Generate new token" → dale un nombre, ej. "Admin destacados"
  3. Repository access → "Only select repositories" → elige automoviles-rueda-catalogo
  4. Permissions → Repository permissions → Contents: Read and write
  5. Generate token, y pégalo aquí arriba (queda guardado solo en este dispositivo)
